## 一、验收思路与证据学规则

### 1.1 定位：本轮的可复用产出是框架，不是器件结论

清单第 P5 项的内容是"数值求解泊松方程 + 载流子连续性方程，复现 PN 结的 I-V 特性"，
并给出两条路线：直接使用 NIST Sesame，或自行实现 Scharfetter–Gummel 离散化。
本项目的取舍是**两条都做，但角色不同**：自研求解器是研究对象（要对它的每个数字负责），
Sesame 是独立的第三方量具（用来证明自研结果不是"自己和自己一致"）。

据此，本轮**不主张任何新的器件物理现象**。真正的交付物是**数值框架本身**
（双势正性表示、广义 SG 通量、解析稀疏雅可比、渐变网格、阻尼 Newton + 自适应延拓），
案例 1–6 的作用是给这套框架提供**分层外部证据**。
全篇因此遵守一条界线：

> **已验证** = 有 `data/metrics_caseN.json` 中的具体测量值直接支撑；
> **外推** = 只有同族/同类算例支撑，或只有机制论证。
> 两者措辞必须可区分，且每一条外推都必须写出它的验证路径。

文中所有"已验证"断言都能在同一目录的 JSON 里按键取到数值；所有外推断言集中在
§1.5.2 的"已验证 / 外推"两栏表中，正文不出现未标注的外推。

**未采用的路线**：清单提到的第二条路线是 FEniCS 有限元。实际未使用，理由是
1D 有限体积 + SG 通量能让"平衡态零电流"和"`np=n_i²`"成为格式的**解析性质**而非拟合结果，
且只依赖 NumPy/SciPy、无构建链、无外部求解器，更贴合"纯 CPU、一键复现"的边界条件。

### 1.2 三层证据结构

仿真类项目最大的验收风险是"曲线好看但没有可证伪的判据"。因此验收拆成三层，
每一层都必须在数值上达到事先声明的门槛：

| 层次 | 对照对象 | 能证明什么 | **不能证明什么** |
|---|---|---|---|
| L1 解析不变量 | 突变结耗尽近似、长二极管 Shockley、`np=n_i²` | 离散格式本身正确、无系统性漏项 | 物理模型是否完备；解析参照本身的适用域 |
| L2 收敛性 | 更细的网格（201→3201） | 解存在极限、可达阶为 2、默认网格已无关 | 极限值是否等于真值（收敛到错的方程也一样二阶） |
| L3 独立实现 | NIST Sesame（零共享代码） | 标量输出（案例 5：端电流 23 点）与**内部剖面**（案例 7：电位/n/p/电场，4 个偏压逐节点）上都不是实现者的一厢情愿 | 两方共同缺失的效应；模型完备性 |

L1/L2 只能自证，L3 才能外证；反过来 L3 只比对同一套模型下的解，差异必须靠 P1–P6 前提
与 L1/L2 才能定位来源。

### 1.3 对照有效性的前提声明（L3 的成立条件）

"**Sesame 与本求解器零共享代码，因此两者差异只来自数值**"这句话**不是无条件的**。
它成立的前提是：两套实现被喂入了同一套**问题**，而不只是同一组参数文件名。
逐条声明并标注保证方式与残余风险：

| # | 前提 | 本项目如何保证 | 残余风险 |
|---|---|---|---|
| P1 | 同一网格 | `sesame.Builder(device.x)` 逐点传入同一数组，`test_material.py` 用 `assert_allclose` 断言 | 无 |
| P2 | 同一掺杂 | `add_donor(N_D, pos<x_j)` / `add_acceptor(N_A, pos≥x_j)`，测试换算回 cm⁻³ 逐区比对 | 无 |
| P3 | 同一材料常数 | ε_r/N_c/N_v/E_g/μ/τ/T 逐项由同一 `Material` 导出 | Sesame 内部取 n_i 的公式与本项目一致（同为 √(N_cN_v)e^(−E_g/2V_t)），已由 V_bi 位级一致反证 |
| P4 | **同一边界条件** | 自研侧：双势 Dirichlet 行把两侧密度钉在平衡值；Sesame 侧：`contact_S` 用表面速度 1e9 cm/s **近似**复现 | **非严格等价**：有限表面速度留下薄层复合残余 |
| P5 | 同一求解容差 | 自研 tol=1e-8（加权 ∞ 范数）；Sesame `tol=1e-9`（其自有范数） | **范数定义不同**，容差数值不可直接比较；残差地板不一致 |
| P6 | 同一物理模型集 | 两者都只含漂移-扩散 + SRH 中间隙陷阱，都无隧穿/俄歇/界面态 | 模型**完备性**一致时差异才只反映数值格式 |

结论：P4 与 P5 是真实残余差值来源。实测最大偏差出现在近零电流的小反偏区
（V=−0.05 V，|J|=1.67e-7 A/cm²，相对偏差 2.85e-4），而大电流区偏差降到 1e-6 量级 ——
即残余差确实集中在边界条件/接触薄层最敏感的区段。
案例 7 把这一句从"推测落在接触"升级为**测量**：在 0.60 V 正偏下，密度偏差的最大点落在
p 接触（x = 119.6 µm，8.50e-4），而离开两侧接触 5 µm 以上的体区只有 2.23e-5；把网格从
801 加密到 1601 节点，接触处的值不减反增（→1.76e-3），体区不变。所以它是 P4 的接触建模差，
不是 P1/P2 的分辨率差。
这**加强**而非削弱本项目的定位：L3 只用于证明格式实现，不用于证明物理完备性。

### 1.4 分层验收闸门（不采用"Sesame 跑通才算通过"）

把 L3 设为通过/不通过的**唯一**闸门会带来两个问题，故不采用：

1. **可及性**：Sesame 需要额外 Python 环境与文件写权限，评审者未必具备，
   会让整体验收结论无必要地依赖外部条件；
2. **判据覆盖不足**：L3 比对的是端电流与内部剖面，但两码共用同一套模型，
   所以它无论如何不能给"PN 结全套特征量"所依赖的**物理完备性**把关；
   真正把关的只能是 L1 的解析不变量与 L2 的收敛性。

因此改为分层闸门，两级都写明结论与适用条件：

| 闸门 | 条件 | 达成后的结论措辞 |
|---|---|---|
| **下限闸门（必须）** | L1 全部不变量 + L2 二阶收敛全绿 | "求解器实现自洽、离散格式正确、网格无关" —— 可交付 |
| **上限闸门（加分证据）** | L3 端电流三位一致 **且剖面判据全绿**（案例 7 的 6 条闸门） | 追加"并与第三方独立实现在标量输出与内部剖面上均一致" |
| 仅 L3 缺失（无 Sesame 环境） | L1+L2 通过 | 只能写"实现自洽性通过、**外部一致性未证**"，标注降级，**不得写"验证通过"** |
| 任一 L1/L2 失败 | — | 不可交付，不得用 L3 通过来抵偿 |

### 1.5 范围边界、可迁移性与统计口径

#### 1.5.1 本轮不做的能力（范围声明）

MOS/MOSFET 电容结构、pin 结、异质结、缓变掺杂结、瞬态与开关、交流小信号导纳、
2D 器件、高注入（V→V_bi 以上）——**本轮均未实现、未验证**。

**PN 结二极管全套**，MOSFET 明确留待后续，不属本轮成果。
本报告与验收表不出现上述任何结构的能力声明或数值结论。

| 断言 | 证据类型 | 状态 |

#### 1.5.3 框架级交付与器件级结果分开统计

本轮交付分两类，混在一起统计会造成"验收过了但能力没验证"的错觉：

| 类别 | 内容 | 验收证据 |
|---|---|---|
| **框架级**（可迁移，与 PN 结无关） | 双势正性表示、Bernoulli 链通量、广义 SG 对 `n_i(x)` 的处理、渐变网格生成器、解析稀疏雅可比、阻尼 Newton + 加权残差 + 自适应延拓、光伏/暗态同一入口 | L1–L3 三层证据均建立在框架性质上；`test_jacobian.py`、`test_bernoulli.py`、`test_mesh.py` 完全不涉及结的几何 |
| **器件级**（只对本器件成立） | 单晶 Si 参数集、突变结 10:1 掺杂、120 µm 长度、1601 节点默认网格、J_s/L_n/L_p/理想因子区段等特征值 | 案例 1–7 的定量比对，全部数值取自 `data/metrics_caseN.json` |

框架级部分已由两个器件（参考 Si / 真实 Si）与一个非平衡算例（光伏产生：
`generation=` 入参、J(0)>0、J_sc 与 `qG(W+L_n+L_p)` 比对、总电流保持连续）实际驱动过。
但"同一套框架能否解 MOS 电容 / pin 结 / 异质结"属**独立验证项**：
它需要新增反型电荷、界面态与带偏移处理（见 §七.2），本轮未包含，
因此本报告只给出"待验证"结论，不据 PN 结的成功外推。

两类在验收表（`reports/acceptance-checklist.md`）中分节列出、不混合计数：
框架级项失败 = 交付物失败；器件级项失败 = 本器件参数/结论需要修订。

#### 1.5.4 跳过 ≠ 通过

Sesame 缺失时 `importorskip` 会让 1 项材料适配器测试、3 项案例 5 交叉测试与

## 二、器件与物理模型

### 2.1 控制方程（稳态）

```
  ∂n/∂t = (1/q) ∂J_n/∂x + U = 0          电子连续性
  ∂p/∂t = -(1/q) ∂J_p/∂x + U = 0         空穴连续性
  ∂E/∂x = -∂ψ/∂x,   ∂(ε ∂ψ/∂x)/∂x = -q(p - n + N_D - N_A)     泊松
  J_n = q μ_n n ∂ψ/∂x + q D_n ∂n/∂x      漂移-扩散
  J_p = q μ_p p ∂ψ/∂x - q D_p ∂p/∂x
  U = G - R,   R = (np - n_i²)/(τ_p(n + n_i) + τ_n(p + n_i))   SRH 中间隙陷阱
  D = μ V_t（Einstein 关系），V_t = kT/q
```

一维稳态下 `∂J_n/∂x = ∂J_p/∂x = 0`，故 `J = J_n + J_p` 为空间常数即端电流；
求解器不对此做任何强制，案例 2 把它作为**待检验的输出**来度量。

### 2.2 器件参数（参考器件，全部案例共用）

| 项 | 值 | 说明 |
|---|---|---|
| 材料 | Si，ε_r=11.7，N_c=2.8e19，N_v=1.83e19 cm⁻³，E_g=1.12 eV | |
| 温度 | 300 K，V_t = 25.85 mV | |
| 迁移率 | μ_n=1350，μ_p=480 cm²/(V·s)（参考器件取常数） | 案例 6 换成 Arora |
| 少子寿命 | τ_n = τ_p = 10 ns | |
| 掺杂 | N_D = 1e17（x<x_j），N_A = 1e16（x≥x_j），突变结 | 10:1 不对称结 |
| 几何 | 器件长 L=120 µm，结位于 x_j=60 µm，两端欧姆接触 | |
| 网格 | 结区 4 nm → 中性区 50 nm 渐变，默认 1601 节点 | `graded_mesh()` |
| 单位制 | cm / V / cm⁻³ / s / A·cm⁻² | `constants.py` |

无量纲化：长度以 Λ=1 µm、密度以 N_ref=max(N_D,N_A,n_i)、电流以
`J_scale = q N_ref D_ref/Λ`、电荷密度以 `R_scale = N_ref D_ref/Λ²` 归一，
泊松系数 `α = q N_ref Λ²/(ε V_t)`。所有未知数以 V_t 为单位，
故 Newton 步长上限可以用一个统一的无穷范数阈值表达。

## 三、数值格式

### 3.1 未知量与正性保证

采用双势（Slotboom）形式，每节点 3 个未知量：`psi, phi_n, phi_p`（单位 V_t），

```
n = r_ni · exp(psi - phi_n)         p = r_ni · exp(phi_p - psi)         r_ni = n_i(x)/N_ref
```

密度始终由指数给出，因此**严格为正**，不会在大偏压下出现非物理负密度或下溢；
代价是方程高度非线性，必须由解析雅可比驱动 Newton（差分雅可比在 4803×4803 规模上不可用）。

泊松方程用有限体积二阶差分（控制体积宽 `hb`、链长 `hd`）。

### 3.2 Scharfetter–Gummel 链通量

对一条链把电势视为线性下降，漂移-扩散 ODE 可精确积分，得到

```
J_n,link = (q D_n/h) [ B(Δ) n_R − B(−Δ) n_L ],      B(x) = x/(e^x − 1)
```

B(x) 与 B(−x) 满足 `B(−x)/B(x) = e^x`，因此当 `phi_n` 沿链为常数
（即 `n_R/n_L = e^Δpsi`）时通量**恒等于零**。
这使平衡态零电流与 `np = n_i²` 成为格式的解析性质，与网格、掺杂台阶、偏压均无关。

Bernoulli 函数实现为三段分支（|x|<1e-3 用 Taylor，|x|>60 用渐近式，中间用 `expm1` 精确式），
`|x|=1e6` 不溢出，分支边界处的跳变在 1e-8 量级（`tests/test_bernoulli.py` 逐项验证）。

### 3.3 带隙窄化下的广义 SG（本项目唯一的格式级修正）

若 `n_i` 随位置变化（带隙窄化、异质结），平衡密度比为

```
n_R/n_L = (n_iR/n_iL) · e^Δpsi        ⇒     Δpsi 不再是让 e^Δ 复现密度比的量
```

此时朴素 SG 在 `n_i` 突变的节点上留下虚假通量。修正方式是把链上 Bernoulli 的自变量
改为**移位压差**：

```
Δ_n = Δpsi + Δln n_i        （电子）
Δ_p = Δpsi − Δln n_i        （空穴）
```

由 `B(−x)/B(x) = e^x` 立刻得到：`phi` 为常数时两股通量对任意 `n_i(x)` 同时归零。
`Δln n_i` 是与偏压无关的常量，在每个偏置点重复使用；雅可比中它只改变 Bernoulli 系数
而不改变对 `psi` 的导数符号结构（`solver.py:187-197`）。

**效果实测**（案例 6）：真实器件平衡不变量 0.1251 → 7.99e-14，Newton 迭代 5 → 4 次；
参考器件因为 `Δln n_i ≡ 0`，所有结果逐位不变 —— 即修正在不该起作用时严格退化为原格式。

### 3.4 雅可比、Newton 与收敛判据

* **解析稀疏雅可比**：COO 三元组直接拼装后转 CSR，含链通量对 `psi/phi_n/phi_p` 的
  全部导数与 SRH 项经 Slotboom 密度求导的 `T_psi/T_phin/T_phip`。
  与中心差分（步长 1e-4 V_t）按"行内最大元归一"后逐元素比对，最大偏差 **1.7e-9**，
  方向性乘积 `J·v` 比对偏差 <1e-5，参考器件与真实器件两组都测
  （`tests/test_jacobian.py`）。接触行为精确单位阵。
* **阻尼 Newton**：`spsolve(J,-F)` → 无穷范数步长上限 `du_cap=4 V_t` →
  同一权重下的回溯线搜索（最多 30 次折半）。步长上限不是装饰：强偏压首步会把
  Slotboom 指数打出范围，去掉阻尼后 `V=0.70` 直接发散。
  验证方式是把 `du_cap` 压到 0.5 并要求收敛到同一状态（`test_solver.py`）。
* **加权残差停止准则**：`max|F_i|/s_i`，`s_i` = 该方程自身各项绝对值之和（下限 1.0）。
  绝对残差在 1/h² 放大后无法表达"平衡满足程度"，逐项归一才与网格无关；
  权重在一次 Newton 步内冻结，故迭代本身与朴素 Newton 数学等价（正对角缩放可在
  `J du = −F` 中约掉），只影响接受判据。
  下限由稀疏 LU 决定：1601 节点约 3e-9，对应端电流误差 <1e-6 A/cm²。
* **偏压延拓**：`_advance()` 步进失败即折半（下限 1e-13 V）重试，
  所以 0→0.70 V 全程每点 ≤4 次 Newton，无需人工设步长。
  冷启动（解析耗尽近似初值）只在低偏可用，高偏自动退回延拓。

### 3.5 网格

`graded_mesh()` 在 `1/h` 度量的"索引空间"里等弧长布点：目标间距在结处为 `h_fine`，
`|x−x_j|>spread` 后按二次型增长到 `h_max`。性质（`tests/test_mesh.py` 全部断言）：
严格递增、覆盖全区间、结两侧 10 nm 内必有节点、最细链 <20 nm、
相邻节点间距比 <1.15（无突变，避免二阶差分失去截断误差展开）、
节点数加倍时 h_min 与 h_max **同步减半**（细化比固定 = h_max/h_fine），
掺杂在 x_j 处严格单侧跳变（突变结检查）。

**判读（本项目最有价值的一条物理结论）**：教科书产生电流
`J_gen = q n_i W/(τ_n+τ_p)` 是**上界而非预测值**。它假设整个耗尽层都以限速
`n_i/(τ_n+τ_p)` 产生；而 SRH 速率
`R = (np − n_i²)/(τ_p(n+n_i) + τ_n(p+n_i))` 只有在 **n 与 p 同时低于 n_i**
的"双耗尽窗口"内才达到该限速 —— 玻尔兹曼尾部让多数载流子在耗尽层的大部分区域内
仍高于 n_i，把分母撑大、把速率压低。实测反推的有效产生宽度与双耗尽窗口宽度之比
为 1.058，与整个耗尽宽度之比只有 0.364，即"窗口宽度而非耗尽宽度决定产生电流"。
同时峰值产生率确实达到理论上限的 0.99999，说明限速机制本身实现正确 ——
偏差来自宽度而非速率。

C-V 侧：微分电容 `C=|dQ/dV|`（Q 由高斯定律取 εE_max，避免对耗尽边缘做阈值判定），
ε/C 反推的 W 与解析值全程偏差 ≤1.67 %；Mott–Schottky 线性度 R²>0.9997，
掺杂反演误差 6.5 %、V_bi 截距偏差 43.7 mV —— 两者都是外推法的固有偏差
（拟合区间只到 −0.70 V，需外推 0.08 V 才能到截距），不是求解器误差。

### 案例 6 · 真实硅模型（Arora 迁移率 + Slotboom 带隙窄化）

参考器件关掉两个掺杂相关模型，是为了让 L1/L3 两层有严格对标值；
但 1e17 cm⁻³ 的实硅二极管不能忽略它们。同一几何、同一网格，只换材料模型：

| 量 | 参考器件 | 真实器件 | 变化 |
|---|---|---|---|
| μ_n @N_D=1e17 | 1350 | **780.2** | −42 %（Arora） |
| μ_p @N_A=1e16 | 480 | 405.96 | −15 % |
| n_i 局域提升（E_g 窄 ~24 meV） | 1.000 | **1.602** | 倍 |
| V_bi | 0.780127 V | 0.758804 V | **−21.3 mV** |
| L_n / L_p | 5.908 / 3.523 µm | 5.520 / 2.657 µm | −6.6 % / −24.6 % |
| J_s | 7.865e-11 | 1.492e-10 | **×1.897** |
| E_max(0) / W(0) | 4.551e4 / 0.3331 µm | 4.484e4 / 0.3285 µm | −1.5 % / −1.4 % |
| J @0.30 / 0.45 / 0.60 V | −9.01e-5 / −3.54e-3 / −0.8014 | −1.357e-4 / −6.067e-3 / −1.2351 | **×1.51 / ×1.71 / ×1.54** |
| 中偏理想因子 | 1.383 | 1.330 | — |
| Newton 迭代（全程最大） | 4 | 4 | 不变 |
| **平衡不变量 max‖np/n_i(x)²−1‖** | 6.39e-14 | **7.99e-14** | 仍机器精度 |

**判读**：最后一行是这一案例的核心。带隙窄化让 `n_i` 沿 x 变化，
朴素 SG 会在掺杂突变处留下虚假通量、破坏平衡不变量；
本项目实测该偏差为 **8e-14**（修正前为 0.1251，见 §3.3），
即广义 SG 在真实模型下依然保持平衡精确性。
其余差异（V_bi −21.3 mV、J_s ×1.90、电流 ×1.54）**不是求解器误差而是模型敏感性** ——
它们量化了"把实硅当理想硅算"会带来多大偏差，也是本案例作为物理结果的产出。
Newton 迭代数不因更复杂的模型而增加，说明格式对 `n_i(x)`、`μ(N)` 的引入不敏感。

### 案例 7 · 与 NIST Sesame 的内部剖面对照

案例 5 只比一个标量。端电流对内部形状不唯一：不同的 n(x)、p(x) 分布可以积出同一个 J，
所以那一层从未检验过**解的形状**。本案例把 L3 从标量扩展到逐节点剖面。

读取方式不改 vendored 代码：`IVcurve` 已把每个收敛点整份 pickle 成 `<prefix>_{idx}.gzip`
（`sesame/solvers.py:399-406`），案例脚本用 `load_sim` + `Analyzer` 从公开 API 取回
n、p 与电位，用 `scaling.density` / `scaling.energy` 换算回 cm⁻³ 与 V。
因此 `reference/` 下 24 个 `.py` 的入库 SHA-256 摘要在本案例加入后仍然成立（已复验）。

两条前提不是假设，而是被测量并写进判据：

* **规范（gauge）。** Sesame 的 `v` 以均匀中性区的**本征能级**为电位零点，本求解器以自身
  静电势为准，二者应差一个常数 `−(χ + E_g/2 + (V_t/2)·ln(N_c/N_v))`。
* **接触。** Sesame 通过 `contact_S` 的有限表面速度钉密度，本求解器用 Dirichlet 行。
  因此偏差被**拆成体区（距两侧接触 ≥5 µm）与接触邻域**两部分报告，
  而不是塞进一个最大值里掩盖"差在哪"。

| 指标 | 数值 | 判定门槛（事先声明） |
|---|---|---|
| 电位规范偏移 | **−4.615497472353522 V** | — |
| 与解析本征能级参考之差 | **0.0** | <1e-9 ✅ |
| 该偏移跨 4 个偏压的极差 | **0.0** | <1e-9 ✅ |
| 去规范后电位逐节点最大差 | 2.05e-10（−0.60 V）/ 1.12e-10（0 V）/ 6.52e-11（0.30 V）/ **1.29e-8 V**（0.60 V） | <1e-6 V ✅ |
| 密度最大相对偏差，平衡与反偏 | n 5.44e-9、**p 7.91e-9**（argmax 落在 x≈60.1 µm，即冶金结） | <1e-6 ✅ |
| 密度最大相对偏差，正偏（体区） | 0.30 V：n 1.436e-3、p **1.484e-3**；0.60 V：n 2.23e-5、p 3.04e-6 | <1e-2 ✅ |
| 密度最大相对偏差，正偏（含接触邻域） | 0.60 V：**n 8.50e-4 @ x=119.6 µm（p 接触处）**、p 5.10e-6 @ 4.6 µm（n 接触处） | 仅披露，不作门槛 |
| 电场体区相对偏差 | −0.60 V 3.21e-9 / 0 V 2.38e-9 / 0.30 V 1.87e-9 / **0.60 V 1.50e-7** | <1e-2 ✅ |
| 电场最大绝对差 | 8.02e-4 V/cm（0.60 V） | — |
| 端电流（顺带复算） | 与案例 5 同源，`rel < 5e-3` | ✅ |

**网格自检（关键判读依据）**：把节点从 801 加密到 1601，正偏密度偏差**不减反增**——

| 偏压 | 量 | 801 节点 | 1601 节点 |
|---|---|---|---|
| +0.30 V | n 全局最大相对偏差 | 1.436e-3 | 1.708e-3 |
| +0.30 V | p 全局最大相对偏差 | 1.484e-3 | 1.883e-3 |
| +0.60 V | n 全局最大相对偏差 | 8.50e-4 | **1.757e-3** |
| +0.60 V | p 全局最大相对偏差 | 5.096e-6 | 5.085e-6 |
| +0.60 V | 去规范电位最大差 | 1.29e-8 V | 1.29e-8 V |
| +0.60 V | 电场体区相对偏差 | 1.50e-7 | 1.50e-7 |

因此正偏密度偏差**不是分辨率不足**，而是 §1.3 的 P4（接触处理方式不同）；
`test_sesame_profiles.py` 里有一条断言把这句话变成可执行判据：
接触邻域的最大相对偏差 > 体区最大值的 10 倍。

**判读**：
（i）平衡与反偏下两码把 n、p、ψ、E 同时做到 1e-8 量级相对偏差，即"两个零共享代码的实现
解出同一个函数"，而不只是同一个数；
（ii）规范常数与解析式误差为 0.0，说明比对确实作用在同一物理量上——这条若失败，
整个剖面对照立即失去意义，所以把它做成独立闸门；
（iii）正偏偏差被定位到接触且证明与网格无关，这是对 §1.3 残余风险 P4 的**定量确认**，
不是新增缺陷；
（iv）与案例 5 一样，本案例仍不检验模型完备性（两码共用 DD+SRH），也不提供参照真值。
Sesame 不输出电场，剖面对照里的电场是两码各自对自己的电位做差分的结果，
用的差分模板逐字相同（`−Δψ/Δx` 边缘差分），因此比较的是格式行为而非某个内部量。

墙钟：本求解器 4 个偏压剖面 1.28 s，Sesame `IVcurve` + 4 次 `load_sim` 8.42 s，
含 1601 节点自检的案例总耗时 31.9 s（`--fast` 会跳过）。

**原始数据落盘**：`data/case7_sesame_profiles.csv`（4 偏压 × 801 行 = 3205 行含表头：
`x_um, V_V, n_self, n_sesame, p_self, p_sesame, psi_self, psi_sesame, E_self, E_sesame`），
评审者不跑任何求解器即可逐点复算上述每一个偏差；结构化指标在 `data/metrics_case7.json`。

## 七、局限（明确写出，不做无根据的外推）

1. **稳态、1D**：无位移电流，因此不含 C-V 的频率色散、瞬态开关、交流小信号导纳。
   案例 3 的电容是**准静态微分电容** `dQ/dV`。
2. **突变结**：掺杂在 x_j 处阶跃。MOS 电容（含反型层与镜像本征区）、pin 结、
   缓变结、异质结**本轮均未实现、未验证**。
   接口层面 `Device.cdot` 可注入任意掺杂剖面、`r_ni` 可逐节点变化，
   即框架**结构上支持**这些扩展；但"结构上支持"不等于"数值上验证过"，
   本轮不在验收结论中声称能解这些结构（§1.5.2）。
3. **均匀寿命**、单一 SRH 能级（中间隙）、无俄歇复合、无势垒隧穿/肖特基复合。
   因此 >0.7 V 区间的实际器件会有额外复合通道。
4. **弱注入侧**：上限 0.70 V = 0.90 V_bi。更高偏压下双极输运进入中性区，
   需要重审接触边界条件与 `du_cap`。
5. **交叉验证的覆盖面**：案例 7 已把对照从端电流扩展到**逐节点内部剖面**
   （n、p、去规范电位、各自差分的电场），但仍只覆盖**这一个**突变结、**这一组**物性、
   **这 4 个**偏压点，且 Sesame 不输出电场——剖面对照里的电场是两码用同一差分模板
   对自己的电位做差分的产物，比较的是格式行为而非 Sesame 的某个内部存储量。
   对照的有效性仍受 §1.3 的 P4/P5 两条残余前提限制；正偏侧已定量确认差异来自 P4（接触），
   与网格无关（见案例 7 的 801↔1601 自检表）。
6. **求解器噪声本底 ~1e-6 A/cm²**：在 \|J\|≲1e-3 A/cm² 处任何**相对**指标
   （连续性、双码对数偏差）都失去意义，因此判据类指标一律门控 \|J\|>1e-3 并另给绝对界。
   **例外（口径不同，必须分清）**：案例 5 的 `max_rel_dev` 是**全扫描展示值**，
   门槛取 `|J_ref| > 1e-12`（`scripts/case5_sesame_crosscheck.py:67`），
   目的是保留 23 点里的 22 点参与比对（只排除 V=0 的 8e-27 A/cm²），所以 2.85e-4
   这个最大值的分母是 1.67e-7 A/cm² 的近零电流。同一批数据按 \|J\|>1e-3 重算
   （10 个点）最大相对偏差为 **1.60e-6**：
   `python -c "import csv;r=list(csv.DictReader(open('data/case5_sesame_crosscheck.csv',encoding='utf-8')));print(max(float(x['rel_dev']) for x in r if abs(float(x['J_self_A_cm-2']))>1e-3))"`。
   另：该全扫描最大值**随解释器版本浮动** —— 同一次 CI 中 3.10/3.13 报 9.15e-5、3.12 报 2.85e-4，
   属噪声末位差异被相对量放大；中位偏差三版本一致到 1.292e-6，`agree_to_3_digits` 仅为展示项、
   无任何断言依赖，判据层面不受影响（见 §8.1 的口径说明）。
   案例 7 的逐节点相对指标按**同一原则**处理小量，两种口径都写明：密度用**排除**——
   `min(n_self, n_sesame) ≤ 1e6 cm⁻³` 的节点不进入最大值/RMS（而不是记为零偏差），
   否则耗尽边缘的玻尔兹曼尾会把除法噪声读成两码不一致；电场因为**在器件内部变号**，
   改用**分母下限** `max(|E|, 1e3 V/cm)`，避免过零处的比值发散。
   剖面测试（`test_sesame_profiles.py`）对电场用的是排除口径，比案例脚本更保守。
7. 网格为几何渐变生成，未做自适应（例如按场梯度重分）；案例 4 表明 1601 节点已足够。

## 八、结论

### 8.1 已验证（有直接测量值）

* **框架实现正确**：自研 1D 有限体积 SG 求解器在三层证据上同时达标 ——
  解析不变量（端电流 1.6e-26 A/cm²、`np=n_i²` 偏差 6.4e-14、V_bi 位级一致）、
  二阶网格收敛（W=1.993、J=1.951，1601↔3201 差异 ≤3.3e-5）、
  与 NIST Sesame 2.0 端电流中位偏差 1.29e-6（最大 2.85e-4，出现在 −0.05 V 近零电流区）、
  **并与同一实现逐节点比对内部剖面**（去规范电位 ≤1.29e-8 V；平衡/反偏密度 ≤7.91e-9；
  体区电场 ≤1.50e-7；电位零点之差与解析本征能级参考误差 0.0 且不随偏压漂移）。
* **PN 结全套特征量复现**：I-V、理想因子三段区（1.58/1.12/2.23）、V_bi、W、E_max、
  C-V、Mott–Schottky、SRH 产生电流、少子扩散长度、串阻压降，均与解析/教科书值定量吻合。
* **广义 Scharfetter–Gummel 机制已验证**：当 `n_i` 随位置变化（此处由 Slotboom 带隙窄化
  引起）时，链上 Bernoulli 自变量必须取 **Δψ ± Δln n_i**；否则平衡不变量在掺杂突变处
  破坏到 0.125 量级，修正后回到 7.99e-14，且对 `n_i` 为常数的参考器件**逐位不变**
  （即修正在不该起作用时严格退化为原格式）。
* **本器件的产生电流机制已实测**：教科书 `q n_i W/(τ_n+τ_p)` 在本器件上高估 2.8–9 倍，
  而反推有效产生宽度与"双耗尽窗口"（n 与 p 同时低于 n_i 的区域）宽度之比为 1.058，
  与整个耗尽宽度之比仅 0.364；同时峰值产生率达到理论上限的 0.99999，
  说明偏差来自**宽度**而非速率。
* **模型敏感性已量化**（真实 Si vs 理想 Si，同一几何同一网格）：
  J_s ×1.897、0.60 V 电流 ×1.54、V_bi −21.3 mV、L_p −24.6 %。
* 全部结果一条命令复现，纯 CPU、无外部数据、总耗时 50.9 s（跳过两个 Sesame 对照与网格研究时 ≈8 s）；
  第三方对照代码版本锁定、完整性摘要与原始逐点数据均已归档。

### 8.2 外推（尚未验证，只给验证路径）

* 上述 SG 机制**是否**适用于其它使 `n_i` 随位置变化的成因（异质结带偏移、缓变禁带）：
  只有同族证据，未验证。验证路径 = 构造对应器件并与已知解析/文献剖面比对。
* "双耗尽窗口决定产生电流"是否为普适结论：**不主张**。它是本器件参数
  （τ=10 ns、W≈0.33 µm、1e16–1e17 掺杂、中间隙单能级）下的实测 + 玻尔兹曼尾部机制解释；
  更深耗尽、更长寿命或非突变结下的适用性本轮未检验，故措辞限于本器件。
* 框架能否解 MOS 电容 / pin 结 / 2D：见 §1.5.2 与 §七.2，均未验证，不作声明。
